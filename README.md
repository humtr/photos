# 📷 Photo Organizer v1.0

Windows에서 바로 실행할 수 있는 **안전 최우선** 사진 정리 애플리케이션입니다.
수십만 장의 사진이 섞인 4TB 이상의 대용량 드라이브도 메모리 누수 없이 빠르고 안전하게 정리합니다.

## ✨ 주요 기능 (v1.0 신규)

- **새로운 마법사 UI**: Windows 11 Fluent 디자인이 적용된 5단계 마법사로 누구나 쉽게 사용할 수 있습니다.
- **안전한 실행 (Dry-run)**: 실제 파일을 이동하기 전에 경로 이탈, 파일 덮어쓰기 위험을 미리 검사합니다.
- **읽기 전용 기본값**: 명시적으로 잠금을 해제하기 전까지는 절대 원본 파일을 수정하거나 이동하지 않습니다.
- **스마트 날짜 추출**: 파일명(예: `IMG_20230501.jpg`), 폴더명, 파일 시스템 생성일을 종합하여 가장 정확한 날짜로 폴더(`YYYY/YYYY-MM/YYYY-MM-DD_event`)를 자동 분류합니다.
- **중복 사진 검출**: SHA-256 해시를 사용하여 완전히 동일한 사진을 찾아냅니다.

## 🚀 시작하기

### 실행 방법 (일반 사용자)

배포된 폴더에서 `PhotoOrganizer_v1.exe`를 더블 클릭하여 실행합니다.

### 실행 방법 (개발자)

Python 3.11 이상이 필요합니다.

```powershell
# 1. 의존성 설치 (PySide6 포함)
pip install -e ".[dev,gui]"

# 2. 앱 실행
python -m photos gui
```

## 📚 사용 가이드 (5단계 마법사)

1. **소스 설정**: 정리할 사진이 흩어져 있는 원본 드라이브(예: `D:\`)와, 예쁘게 정리된 폴더가 생성될 대상 드라이브(예: `D:\PICTURES`)를 선택합니다.
2. **필터 규칙**: `.thumbnails`나 클라우드 동기화 폴더(`Google Photos`) 등 불필요한 폴더를 정리 대상에서 제외합니다.
3. **통계 대시보드**: `스캔 시작`을 누르면 흩어진 파일들의 총 용량과 사진 개수를 분석하여 보여줍니다.
4. **사진 검토**: 분석이 끝나면 `정리 계획 생성`을 눌러 파일들이 어떤 폴더로 이동할지 미리보기 트리로 확인합니다.
5. **정리 실행**: `Dry-run 실행`을 눌러 안전 검사를 통과한 후, **읽기 전용 해제** 체크박스를 켜고 실제 파일 이동을 시작합니다.

## ⚠️ 주의 사항

- **긴 경로 지원**: Windows의 기본 260자 경로 제한을 넘는 깊은 폴더 구조도 안전하게 처리하도록 설계되었습니다.
- **복구(Undo)**: 파일 이동 후 생성되는 `_review/undo_plan.csv` 파일을 참조하여, 필요한 경우 수동으로 파일을 원래 위치로 되돌릴 수 있습니다.
- **백업 권장**: 앱이 최대한 안전하게 동작하도록 설계되었으나, 대규모 파일 이동 전에는 반드시 **중요 파일의 백업**을 권장합니다.

---
*Photo Organizer는 사진 보관의 본질인 "날짜 기반의 안정적인 폴더 구조"를 지향합니다.*
